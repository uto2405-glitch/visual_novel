# 폰으로 쓰기 — LAN 접속 · 이미지 올리기 · 홈 화면에 추가

침대에서 폰으로 감상하고, 폰에서 만든 이미지를 바로 장면에 넣는 방법.
**아무것도 인터넷에 올리지 않는다.** 폰과 PC 가 같은 와이파이에 있으면 그걸로 끝이다.

---

## 1. PC 에서 LAN 모드로 켜기

```powershell
powershell -ExecutionPolicy Bypass -File start_studio.ps1 -Lan
```

또는 스튜디오만:

```
python tools/webapp.py --lan
```

콘솔에 이렇게 뜬다:

```
========================================================
LAN 모드 — 같은 와이파이의 폰/태블릿에서 아래 주소로 접속:
  http://192.168.0.12:8765/

  접속 PIN:  418320   ← 폰 화면에 이 숫자를 입력하세요
  (이 PC 화면 = 127.0.0.1 접속은 PIN 없이 그대로 사용)
⚠ 신뢰된 와이파이에서만 쓰세요.
  (API 키는 여전히 서버에만 있고 브라우저로 전달되지 않습니다.)
========================================================
웹 스튜디오 실행: http://127.0.0.1:8765/
XAI_API_KEY: 미설정 (스토리/장면구성 탭은 수동 모드로)  |  로그: logs/webapp.log  |  종료: Ctrl+C
  PIN 을 놓쳤다면: logs/lan_pin.txt
```

### 접속 PIN — LAN 모드의 기본값

**`--lan` 을 쓰면 6자리 PIN 이 자동으로 켜진다.** 서버를 켤 때마다 새로 뽑히고,
서버를 끄면 무효가 된다. 외부 기기(폰·태블릿)가 처음 접속하면 PIN 입력 화면이 먼저 뜬다.

- **이 PC 에서 `127.0.0.1` 로 여는 화면은 PIN 을 묻지 않는다.** 로컬 작업은 그대로 편하다.
- 콘솔을 놓쳤거나 스크롤로 지나갔다면 **`logs/lan_pin.txt`** 에 이번 실행의 PIN 이 적혀 있다.
- 매번 같은 숫자를 쓰고 싶으면 `python tools/webapp.py --lan --pin 4726` (4~6자리 숫자).
- PIN 없이 쓰려면 `--no-pin`. **권하지 않는다** — 아래 §6 을 먼저 읽자.

### 처음 한 번: 방화벽 허용

Windows 방화벽이 "Python 의 네트워크 접근을 허용하시겠습니까?" 를 묻는다.
**개인 네트워크(Private)** 에 체크하고 허용한다. 공용 네트워크는 체크하지 않는다.

이 창을 놓쳐서 폰이 접속되지 않으면, 서버를 껐다가 다시 켜면 다시 묻는다.

## 2. 폰에서 접속

1. 폰이 **PC 와 같은 와이파이**에 붙어 있는지 확인한다 (5GHz/2.4GHz 는 달라도 보통 같은 망이다).
2. 폰 브라우저 주소창에 콘솔에 뜬 주소를 그대로 친다: `http://192.168.0.12:8765/`
   - `http://` 를 빼면 검색어로 인식되니 그대로 입력한다.
3. **PIN 입력 화면이 뜬다 — 정상이다.** PC 콘솔에 뜬 6자리를 넣는다.
4. 스튜디오 화면이 뜬다. 즐겨찾기에 넣어 두면 다음부터 한 번에 들어간다.

### 접속이 안 될 때

| 증상 | 원인 | 해결 |
|---|---|---|
| **PIN 입력 화면이 뜸** | 정상 동작 (LAN 기본값) | PC 콘솔의 6자리를 입력. 놓쳤으면 `logs/lan_pin.txt` |
| PIN 이 안 맞음 | 서버를 다시 켜서 PIN 이 바뀜 | 새로 뜬 PIN 을 쓴다. 고정하려면 `--lan --pin 4726` |
| `입력 시도가 많습니다` | 5회 연속 실패 → 무차별 대입 방지 잠금 | **1분** 기다렸다 정확한 PIN 으로 다시 시도 |
| 연결 안 됨 | 방화벽 차단 | 서버 재시작 후 방화벽 팝업에서 "개인 네트워크" 허용 |
| 연결 안 됨 | 폰이 셀룰러(LTE/5G) 사용 중 | 와이파이 켜기 |
| 연결 안 됨 | 게스트 와이파이 / AP 격리 | 기기 간 통신을 막는 망이다. 메인 와이파이로 옮긴다 |
| 어제 되던 주소가 안 됨 | PC 의 LAN IP 가 바뀜(DHCP) | 콘솔에 새로 뜬 주소를 쓴다. 자주 바뀌면 공유기에서 고정 IP 할당 |
| `forbidden host` | 콘솔에 없는 주소로 접속 | 콘솔이 알려준 IP 를 그대로 쓴다(호스트 헤더 검증) |
| `PIN 인증이 필요합니다` (401) | 인증 쿠키 만료·삭제 | 페이지를 새로고침하면 PIN 화면이 다시 뜬다 |

## 3. 폰에서 할 수 있는 것

화면 왼쪽(작은 화면에서는 위쪽 가로 바) 탭 구성:

**소설 만들기** — 스토리 / 장면 / 검사
**감상** — 뷰어 / 갤러리 / 대화

| 탭 | 폰에서 |
|---|---|
| **스토리** | 로컬 LLM 과 대화하며 스토리라인 쓰기 |
| **장면** | 장면 카드 확인, 프롬프트 생성·복사, 이미지 업로드, 선택, **승인 도장** |
| **검사** | 검사기 실행 결과 확인 |
| **뷰어** | 비주얼 노벨 재생 — 탭으로 넘기기, 스와이프, 자동 재생, 세로 스크롤 모드 |
| **갤러리** | 승인 컷 모아 보기 |
| **대화** | 인물과 대화. 어울리는 앨범 사진을 보내 주기도 한다 |

로컬 LLM 이 답하는 데 수십 초 걸릴 수 있다. **화면을 끄지 말고 기다린다.**

## 4. 폰에서 이미지 넣기 (📤 업로드)

폰에서는 `images/raw/` 폴더에 파일을 직접 넣을 수 없다. 그래서 업로드 버튼이 있다.

1. **장면** 탭에서 이미지를 넣을 장면 카드를 찾는다.
2. **[📤 이미지 업로드]** 를 누른다. (승인된 장면에는 이 버튼이 없다 — 잠겨 있다.)
3. 폰의 사진첩·카메라·파일 중에서 고른다.
4. 업로드되면 **자동으로 후보 등록 + 자동 검사**까지 진행된다.
   `업로드+검사 PASS (후보 3장)` 처럼 결과가 표시된다.
5. 썸네일에서 쓸 컷을 눌러 선택하고, 마음에 들면 **[승인 도장 찍기]**.

제약
- png / jpg / jpeg / webp / tif / tiff 만. 30MB 이하.
- 파일명은 안전한 문자만 남겨 저장된다(같은 이름이면 `-2`, `-3` 이 붙는다).
- **승인된 장면은 업로드·재스캔이 잠긴다.** 바꾸려면 먼저 되돌려야 한다:
  `python tools/advance_scene.py revise SCENE-00X IMAGE`

## 5. 홈 화면에 추가 / 오프라인으로 갖고 다니기

### 바로가기 (LAN 접속 유지)
폰 브라우저 메뉴 → "홈 화면에 추가". 아이콘을 누르면 스튜디오가 열린다.
**단, PC 서버가 켜져 있고 같은 와이파이일 때만** 동작한다. 밖에서는 열리지 않는다.

### 진짜 오프라인 소장본 (권장)
감상본을 파일 하나로 구워 폰에 복사한다. 서버도, 와이파이도, 인터넷도 필요 없다.

```
python tools/export_viewer.py          # output/viewer/ 에 단일 HTML
python tools/export_pwa.py             # output/pwa/ (index.html + 아이콘 + sw.js)
```

이 HTML 안에는 이미지가 통째로 들어 있어 **혼자서 열린다.** USB 케이블로 폰에 복사한 뒤
파일 앱에서 열면 끝이다.

> **알아둘 기술적 사실:** PWA 의 오프라인 캐시(서비스 워커)는 **HTTPS 또는 localhost 에서만**
> 등록된다. `http://192.168.x.x:8765/` 같은 LAN 주소에서는 동작하지 않는다.
> "홈 화면에 추가"로 아이콘은 생기지만 오프라인 실행은 안 된다.
> 그래서 오프라인 소장은 **호스팅이 아니라 파일 복사**가 정답이다.
> 공개 호스팅을 고민 중이라면 먼저 [PRIVACY_HOSTING.md](PRIVACY_HOSTING.md) 를 읽어야 한다.

## 6. LAN 모드 안전 수칙

`--lan` 은 `0.0.0.0` 에 바인딩한다. **같은 네트워크의 모든 기기가 접속할 수 있다.**
접속한 사람은 승인 도장을 찍거나 이미지 생성을 눌러 **과금을 발생시킬 수도 있다.**

### PIN 을 끄지 마라 — 이게 과금 오용을 막는 유일한 장치다

이미지 생성 버튼 한 번이 곧 MakeFun 종량제 과금이다. PIN 이 없으면 같은 와이파이에 붙은
아무 기기나 브라우저로 그 버튼을 누를 수 있다. 승인 도장(사람 게이트)도 마찬가지다.
그래서 **LAN 모드는 PIN 을 기본으로 켠다.** `--no-pin` 은 나 혼자 쓰는 격리된 망에서,
그 위험을 알고 고를 때만 쓰는 탈출구다. 껐을 때는 콘솔이 경고를 띄운다:

```
⚠ PIN 없음(--no-pin): 같은 네트워크의 다른 기기도 그대로 조작할 수 있습니다.
```

PIN 은 접속 문턱일 뿐 암호화가 아니다. LAN 안의 통신은 평문 HTTP 다 — 신뢰된 망 전제는
PIN 이 있어도 그대로 유효하다.

- 집 와이파이에서만 켠다. 카페·회사·공용 와이파이에서는 켜지 않는다.
- 다 쓰면 서버를 끈다 (콘솔에서 `Ctrl+C`). 그 순간 PIN 도 `logs/lan_pin.txt` 도 무효가 된다.
- API 키·토큰은 어떤 모드에서도 브라우저로 전달되지 않는다. 서버에만 남는다.
- 기본 모드(`--lan` 없이)는 `127.0.0.1` 전용이라 이 PC 밖에서는 아예 보이지 않는다.
