# 프로토콜 상태 — AI 웹툰 제작 시스템
최종 갱신: 2026-08-24 (v5.1 점검·보완)

## 목적 (확정문)
Grok AI가 스토리를 씬·행동 비트·장면으로 분해하고, 각 장면의 연출/구도와 외부 상용 이미지 AI용 프롬프트를 생성한다. 생성된 이미지는 캐릭터·배경·소품의 일관성과 인쇄 품질을 검수한 뒤 대사/말풍선과 함께 비주얼 노벨처럼 한 장면씩 감상할 수 있는 결과물로 구성한다. 최종 산출물은 디지털 감상용 장면 묶음과 실제 사진 출력에 적합한 고해상도 이미지다.

- 상태: 첫 작품 투입 대기

## 열린 질문 / 보류 결정
- 외부 상용 이미지 생성 AI: 사용자 보유 제품 있음(정보 제공 대기). Grok은 오케스트레이션 및 프롬프트 설계 역할로 고정.
- 출력 용도: 개인 소장 인화로 확정(출간 아님). 인화 크기는 작품별 지정, 기본 기준 긴 변 1024px.
- Grok 연동: 수동 모드로 확정 시작(SuperGrok 구독, 비용 0). API 모드 스크립트(grok_api.py)는 준비 완료 — 분량 증가로 필요해지면 console.x.ai 키 발급 후 manifest 의 orchestrator.api.model 만 기입하면 즉시 전환. 모델명은 발급 시점에 docs.x.ai 에서 확인.
- SuperGrok OAuth 우회 경로는 403 불안정으로 채택하지 않음 (기록).
- 디지털 감상용 런타임(HTML/영상/앱)은 추후 선택.
