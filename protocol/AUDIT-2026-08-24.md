## B. 검사기 제안 (check_protocol.py — 에이전트 수정 금지, 사용자 승인 필요)

아래는 전부 **검사를 더 엄격/견고하게** 만드는 변경이라(현재의 일부 PASS→FAIL, 크래시→FAIL),
"채점표를 고쳐 PASS를 만드는" 금지 행위와 정반대다. deny를 잠시 해제하고 지시하시거나 직접 적용하세요.
적용 후 `SCORECARD.md` "개정 이력"에 기록하고 deny 복구를 권장합니다.

1. **[high] 판독 불가 이미지가 APPROVED로 통과** (line ~311): 0바이트/손상 PNG는 `image_size()`가 None →
   `A3 SKIP`이라 승인 통과. → **REVIEW_HUMAN/APPROVED 단계의 selected_image는 size=None을 SKIP이 아니라 FAIL로**.
2. **[high] 씬 파일 최상위가 dict 아님** (line ~184): `sc.get(...)` AttributeError 크래시. → load 직후 `isinstance(sc,dict)` 아니면 A1/A2 FAIL 후 continue.
3. **[medium] manifest 최상위가 dict 아님** (line ~141): `required - set(manifest)` TypeError. → `isinstance(manifest,dict)` 가드.
4. **[medium] min_long_edge_px 문자열** (line ~169): `int < str` TypeError로 검사 중단. → `int()` 강제, 실패 시 A1 FAIL.
5. **[medium] min_long_edge_px ≤ 0** (line ~313): 해상도 게이트 무력화. → 양의 정수 검증, 아니면 DEFAULT로 대체 + FAIL.
6. **[medium] grok_output이 dict** (line ~256): `.strip()` AttributeError. → `isinstance(out,str)` 아니면 A6 FAIL.
7. **[medium] dialogue 원소가 dict 아님** (line ~225): `line.get` AttributeError. → `isinstance(line,dict)` 가드.
8. **[medium] A6 앵커 우회** (line ~269/274): 실제 anchor 없이 리터럴 ID(CHAR-001/LOC-001)만 있어도 PASS. → id 폴백 제거(또는 WARN 분리)하여 prompt_anchor 원문 포함 강제.
9. **[medium] A8 키스캔 확장자 갭** (line ~345): `.html/.js/.csv/.toml`, 줄바꿈 분할 키 미검출. → text_exts 확장 + 공백 허용 정규화.

> 참고: `tools/studio.html`은 실제 프론트 파일인데 A8 스캔 대상 확장자가 아니라, 만약 키를 하드코딩하면 A8이 놓칩니다(9번). 현재 저장소엔 키가 없어 실제 유출은 없음.
