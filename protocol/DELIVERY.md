# 전달물 규격

## 디지털 — 비주얼 노벨형
각 Scene을 하나의 감상 단위로 유지한다.

권장 데이터:
- 장면 이미지
- speaker_id
- dialogue text
- 대사 표시 위치
- 장면 순서
- 장면 전환 정보
- 선택지(사용할 경우)

최종 런타임은 HTML/영상/앱 중 프로젝트 목적에 따라 선택한다.

## 실물 — 사진 출력
작품별로 다음을 먼저 확정한다.
- 사진 출력 크기
- 종횡비
- 최종 픽셀 크기
- 색상 처리 방식
- 재단/여백
- 파일 형식

사진 출력 규격이 확정되기 전에는 임의의 DPI/용지 프로필을 최종값으로 고정하지 않는다.
