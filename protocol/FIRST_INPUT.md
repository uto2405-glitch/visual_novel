# 첫 작품 투입 입력 형식

다음 중 가능한 것만 제공하면 된다. 빈 항목은 프로토콜이 초안으로 채운다.

## 최소 입력
- 작품 제목:
- 원하는 장르:
- 전체 이야기 또는 이번 화의 대략적인 내용:
- 원하는 분위기/화풍:

## 선택 입력
- 주요 등장인물 설명:
- 배경 설명:
- 예상 분량:
- 실제 사진 출력 크기:
- 참고 이미지/기존 디자인:
- 사용 예정 외부 이미지 AI:

## 시작 규칙
최소 입력만 있어도 BRIEF → STORY → CAST → SCENE_PLAN 순서로 정리한다.
사용자 승인을 받은 뒤 첫 Scene의 PROMPT 단계로 이동한다.
